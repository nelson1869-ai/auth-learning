## ✅ Checkpoint (`checkpoint-senior`): *Kaya mong ipaliwanag ang bawat bahagi ng system — nang hindi tumitingin sa code.*

> ✍️ Sinulat ng AI sa hiling ko, sa salitang parang ako. **Hindi ko pa ito napapatunayan.** Ang tag na `checkpoint-senior` ay HINDI pa ginawa:
> gagawin lang ito kapag naipaliwanag ko ang mga tanong sa ibaba nang hindi tumitingin (sa AI, o sa sarili kong pagsulat).

**Ang paglakbay ng isang login, mula sa pindot hanggang sa sagot:**
1. **Browser** (`nelson1869.com`, Cloudflare Pages): ang React page ay nagpapadala ng `POST /api/auth/login` sa `api.nelson1869.com`, may `credentials: 'include'`.
2. **Cloudflare** → **Tunnel** → ang `cloudflared` container sa PC ko → `backend:3000`. Walang bukas na port sa router.
3. **Express**: request ID at log → security headers → CORS (`CLIENT_URL` lang) → CSRF (Origin) → JSON → cookies → ang route.
4. **Rate limiter** (Redis, fail-open) → **controller** (Zod: tamang hugis) → **service**.
5. **Service**: hanapin ang user; kunin muna ang numero ng subok (atomic) **bago** ang argon2; laging may argon2 kahit walang account (pareho ang oras); 5 mali → 423.
6. Tama → isang **transaction**: refresh token (hash lang ang naka-save) + trusted device. Pagkatapos lang: ang mga cookie (httpOnly, SameSite=Lax, Secure).
7. **Access token** = JWT, RS256, 15 minuto, walang row sa database. **Refresh token** = 7 araw, nasa database, kayang bawiin; bawat gamit ay bagong token, at ang lumang ginamit ulit = nakaw → bawiin ang buong family.
8. Ang audit log, ang metrics, at — kapag may mali — ang alert email.

**Ang passkey, sa isang talata:** ang device ang gumagawa ng key pair; public key lang ang nasa server. Sa login, pumipirma ang device sa isang challenge na isang beses lang magagamit, kasama ang origin na inilagay ng browser. Kaya walang password na mananakaw, at walang silbi ang pirma sa pekeng site.

**Mga tanong na dapat kong masagot nang walang tinitingnan:**
1. Bakit httpOnly cookie, at hindi `localStorage`?
2. Bakit dalawang token (access at refresh), at ano ang mangyayari kapag ginamit ulit ang lumang refresh token?
3. Bakit pareho ang oras ng sagot sa login, may account man o wala?
4. Bakit `DELETE … RETURNING` ang pagkuha ng challenge, at hindi `SELECT` tapos `DELETE`?
5. Ano ang pagkakaiba ng `/health/live` at `/health/ready`, at bakit `users` ang tinatanong ng ready?
6. Bakit hindi puwedeng mag-restore sa pooled URL ng Neon?
7. Bakit fail-open ang rate limiter, at ano ang bantay kapag patay ang Redis?
8. Bakit hindi random ang decoy?
